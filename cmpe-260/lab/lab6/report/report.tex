\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}

The objective of this exercise is to assemble multiple stages of a MIPS
processor into one pipelined, functioning design. Registers were created
between each stage. Each register was updated on the clock edge. A testbench
was created with a test case for each instruction type. All test cases passed;
the exercise was successful.
