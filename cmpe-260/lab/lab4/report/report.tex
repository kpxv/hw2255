\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}

The purpose of this exercise was to design and implement an n-bit multiplier
in an ALU and the wrapper for the Execute Stage of a MIPS processor, as well as
to test the entire Execute Stage and its components. Multiplier designs were
considered, and the carry-save design was selected to be implemented for its
speed. The multiplier functionality was added to a previously implemented n-bit
ALU design. An Execute Stage wrapper was implemented to process input signals
and determine the correct input for the ALU and the correct outputs for
destination registers. The multiplier was tested against a testbench designed
to ensure correctness when handling carries, large numbers, small numbers, the
number 0, and the number 1. The entire Execute Stage was tested against a
testbench that verified the functionality of signal resolution and of each
basic ALU operation. All tests for both testbenches passed; the exercise was
successful.
