\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}

The purpose of this exercise was to design, implement, and test an n-bit
Arithmetic Logic Unit (ALU) to support multiplication, addition, loigcal left-
and right-shifts, arithmetic right-shifts, logical AND, logical OR, and logical
XOR; as well as to create an execute stage to map input flags and register and
memory values to the ALU. The partial n-bit ALU from Laboratory Exercise One
was expanded upon with a carry-save multiplier and a ripple-carry adder.
Testbenches were written for the multiplier, the expanded ALU, and the complete
execute stage. Behavioral, post-synthesis timing, and post-implementation
timing simulations were ran using the testbenches. N was set to four, and the
expanded ALU was flashed to a Basys3 FPGA. All tests passed and the hardware
implementation worked as expected; the exercise was successful.

The purpose of this exercise was to design, implement, and test the execute
stage of a MIPS processor. The execute stage featured an Arithmetic Logic Unit
(ALU) that supported eight operations: multiplication, addition, logical left-
and right-shift, arithmetic right-shift, and logical AND, OR, and XOR. The
execute stage mapped flags and register and memory values into the ALU.
Testbenches were written for the ALU, the multiplier, and the execute stage.
Testbenches were run with behavioral, post-synthesis timing, and
post-implementation timing simulations. All three testbenches passed,
confirming the correctness of the ALU, multiplier, and the execute stage. Thus,
the exercise was successful.
